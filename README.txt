FILES
1. index.html     - Home page, lessons and register/login form
2. dashboard.html - Student dashboard and saved lesson bookings
3. style.css     - Website design and responsive layout
4. script.js     - Simple JavaScript interactions and localStorage

HOW TO RUN
1. Extract the ZIP file.
2. Keep all four files in the same folder.
3. Open index.html in Chrome, Edge, Firefox or another browser.
4. Click Login / Register and fill the form.
5. Choose a lesson and click Book lesson.
6. Open My Dashboard to view or cancel your booking.

NO INSTALLATION REQUIRED
This simple version does not require Node.js, MongoDB, Express, or a terminal.

IMPORTANT LIMITATION
This is a frontend demonstration. It stores demo information in the browser's localStorage.
It is NOT secure authentication and should not be used for real accounts or sensitive data.

PROJECT TECHNOLOGIES
HTML: provides page structure.
CSS: controls colours, spacing, layout, and mobile responsiveness.
JavaScript: handles the form, booking buttons, dashboard, and cancellation.
localStorage: saves demo data in the same browser.
